## Evidence and verification

The dated software evidence describes its recorded source revision and test
environment. Packaging does not rerun firmware builds or establish physical
robot performance. Kit photographs identify hardware; they are not test results.

MANIFEST.json records every payload file's size, mode, hash and origin; it does
not include itself or PACKAGE_FILES.sha256. PACKAGE_FILES.sha256 covers the
payload and MANIFEST.json, excluding itself. From this extracted folder, run
`sha256sum -c PACKAGE_FILES.sha256` in Ubuntu/WSL to verify those files.
The ZIP's own SHA-256 is provided next to the archive as a separate .sha256 file.
