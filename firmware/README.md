# Robot firmware tooling

The robot application itself is in [app_program/](../app_program/). This folder
holds its host tests ([tests/](tests/), [run_tests.sh](run_tests.sh)), the
check, build and measurement scripts ([scripts/](scripts/)), third-party
licence notices, the bench program the mission was developed in on the car
([bench/](bench/), with its frame format `FRAMES.md`) and the host simulator
of the robot app running the mission ([robot/sim/](robot/sim/)). See
[the repository guide](../README.md) for setup, checks and limitations.
